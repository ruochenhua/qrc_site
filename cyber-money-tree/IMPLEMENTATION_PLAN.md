# 赛博发财树实施计划

## 已锁定的产品约定

- 主流程：浏览共享树和叶笺墙 → 浇水并得到全站序号 → 收下一张其他访客留下的叶笺 → 选择海报与安全短语 → 把自己的叶笺送给下一位。
- 每张叶笺由一个预制海报主题和词库拼成的短句组成。没有自由文本、图片上传、评论或回复。
- 访客无需注册。随机匿名浏览器编号用于标记“本设备”参与次数；收到的叶笺册存于本地浏览器。
- 公共叶笺墙每次展示最多 10 张：先取 3 张高赞，再随机抽 7 张；当前批次按点赞数排序。访客每个浏览器对每张叶笺可点赞一次，可主动换一批；完整大海报仍仅用于来信和收藏册。
- 树有 10 个视觉等级：办公室、窗边、窗外、楼体、屋顶、天台、街区、城市、行星、银河。等级门槛集中配置，早期等级间隔短，后期拉长。
- 美术基调：阳光明媚、清楚的 16-bit 像素块、色彩鲜明、轻松夸张、避免写实与二次元。背景按办公室 → 楼体 → 城市 → 太空分章；树的十级形态覆盖其上。
- 全站计数和公开叶笺需要服务端。子项目使用 Cloudflare Worker + D1；Worker 同时提供静态页面和 API，保证本地一条命令启动。
