# QRC-Eye 全站 Y2K 视觉改造设计

日期：2026-07-19
状态：已获用户批准

## 背景与目标

QRC-Eye 个人站（静态站点，GitHub Pages 托管）目前为深色极简风格。本次改造在不改变页面内容与信息结构的前提下，将全站视觉升级为 **Y2K / 复古未来 · 控制台方案**，提升三点：

1. 文字排版（Y2K 风格中英混排字体系统）
2. 动态反馈（定制光标、故障微交互、跑马灯、复古音效）
3. 动态 3D 表现（Three.js 主视觉 + 轻量点缀）

## 已对齐的决策

| 维度 | 决策 |
|------|------|
| 风格 | Y2K / 复古未来，「控制台」概念（金属铬、扫描线、等宽/像素字体、霓虹绿点缀） |
| 范围 | 全站统一：主页 + dev-blog 完整换皮；游戏页面内部不动，仅注入 Y2K 外壳（顶栏 + 启动画面） |
| 3D 角色 | 主页 Hero 可交互主视觉 + 子页面轻点缀 |
| 字体 | 英文/数字用网络展示字体（像素体 + 等宽体），中文用系统字体 + CSS 效果 |
| 动态反馈 | 全选：定制光标+拖尾、故障/霓虹微交互、滚动跑马灯+视差、复古音效（默认静音） |
| 性能 | 桌面拉满，移动端自动降级，遵循 `prefers-reduced-motion` |
| 内容 | 结构与文案不变，只换皮 |

## 技术架构

新增共享主题包，全站页面引用同一套资源：

```
assets/y2k/
├── theme.css      # 设计令牌（配色/字体/效果）+ 通用组件（按钮、卡片、跑马灯、扫描线）
├── fx.js          # 动效套件：定制光标+拖尾、故障微交互、滚动视差、降级逻辑
├── sfx.js         # WebAudio 振荡器合成 8-bit 音效（无音频文件）
└── hero3d.js      # Three.js Hero 主视觉（仅主页加载）
```

关键决策：

- **Three.js 通过 CDN + import map 引入**，仅主页 Hero 加载，子页面零 3D 开销。CDN 失败时优雅降级为 CSS 金属渐变静态标题，不白屏不报错。
- **主页弃用 Tailwind CDN**，改用 `theme.css` 手写样式（Y2K 需要大量自定义效果，Tailwind 反而是束缚）。布局结构不变。
- **降级逻辑集中在 `fx.js`**：
  - `matchMedia('(pointer: fine)')` → 是否启用定制光标
  - `matchMedia('(max-width: 768px)')` → 移动端关闭 3D、拖尾
  - `prefers-reduced-motion` → 关闭所有非必要动画
- **游戏页面**（cybertravel / firework-master / kings-field）：游戏内部代码一行不动，仅外层注入 Y2K 顶栏（返回首页 + Logo）和「INSERT COIN」式启动画面。
- **音效默认静音**，右下角复古开关，用户主动开启（同时满足浏览器自动播放策略；iOS 需用户手势启动 AudioContext）。

## 视觉系统

### 配色

- 基底：近黑蓝灰 `#0a0c10` + 全屏 CRT 扫描线纹理（CSS 渐变实现，纯装饰）
- 主金属色：银灰铬渐变 `#e8e8ec → #9a9aa5 → #d5d5dd`（大标题、3D Logo 材质）
- 点缀：霓虹绿 `#39ff6a`（交互态、光标、徽章）+ 信号黄 `#ffe14d`（跑马灯、标签）
- 辅助：冷蓝 `#7da2ff`（链接、次级信息）

### 字体与排版

- 英文/数字标题：像素/展示体（`Silkscreen` 或 `VT323`，实现时二选一）
- 英文界面正文/标签：等宽体（`Space Mono` 或 `IBM Plex Mono`），全大写 + 加宽字距
- 中文：系统字体（苹方/微软雅黑）；标题加铬渐变填充 + 1px 错位描边阴影（故障感），正文保持干净浅灰保证可读性
- 区块标题带 `[ ]` / `//` 控制台式装饰；状态徽章改为 LED 点阵灯样式

### 组件换皮（结构不变）

- 项目卡片：深色面板 + 1px 金属边框；hover 时边框变霓虹绿、扫描线扫过、标题 glitch 抖动
- 按钮：金属渐变立体按键（老式播放器风格），按下有凹陷位移
- 跑马灯：Hero 与项目区之间一条黄底黑字横向滚动带（`★ NOW PLAYING ★ CYBERTRAVEL ★ …`）

## 3D 主视觉（仅桌面端主页）

- 主体：挤出金属立体字 `QRC-EYE`（`ExtrudeGeometry` + 高反光金属材质），中央悬浮缓慢自转
- 环境：无限线框网格地面（shader，透视消失于地平线）+ 深空渐变背景
- 交互：鼠标移动 → Logo 朝指针弹性倾斜；滚动 → Logo 缩小上移让位内容
- 降级：移动端 / `prefers-reduced-motion` / WebGL 不可用 → CSS 金属渐变静态标题 + 静态 SVG 网格

## 动效清单（fx.js）

- 定制光标：十字准星，悬停可点元素变霓虹绿放大；Canvas 像素星星拖尾（6-8 帧）
- 故障微交互：hover 卡片/按钮标题 glitch 0.3s；关键文字每 8-12s 随机一次轻微 RGB 分离闪烁
- 滚动反馈：区块进入视口弹性淡入（保留现有行为、换更脆的曲线）；Logo 与卡片轻微视差
- 音效（默认静音）：hover 短促「哔」，点击「哔-啵」双音，WebAudio 振荡器合成
- 启动画面：首次访问主页约 1s 的「SYSTEM BOOT / LOADING…」假加载条；`sessionStorage` 记录同会话只播一次，可点击跳过

## 错误处理

- Three.js / 字体 CDN 失败 → try/catch 兜底静态样式，console 警告
- 沿用现有 `handleError` 模式；sfx 模块所有 AudioContext 调用外包 try/catch

## 验证方式

- 本地 `python3 -m http.server` 起服务，桌面 Chrome/Safari + 移动端模拟目检
- DevTools 模拟 `prefers-reduced-motion` 验证降级
- Lighthouse：移动端 Performance ≥ 80
