# W3：主页接入、质量验证与发布

父规划：[交互式像素世界主页总规划](2026-10-01-interactive-pixel-world-master.md)<br>
规格：[设计规格](../specs/2026-10-01-interactive-pixel-world-design.md)<br>
依赖：W0、W1、W2 全部通过

**目标：** 将主页收敛为铺满浏览器视口的可探索像素 RPG。正常状态只呈现游戏世界与少量 HUD；不在游戏下方显示项目、笔记或关于列表。项目作为地图物件互动。脚本、引擎或素材故障时，在同一视口显示静态回退页。

## 任务

- [x] **W3.1 全屏游戏主页与渐进降级**
  - 首页只保留全屏场景、品牌 HUD、开发笔记入口和键位提示；不渲染游戏下方的项目/笔记/关于内容。
  - SEO 元数据与 RSS 保留；项目卡片只放在默认隐藏的全屏错误回退中，并由 `WORLD-PROJECTS` 生成区维护。
  - JavaScript 被禁用时，用 `<noscript>` 触发同一全屏入口页；运行时成功时不显示回退卡片。
  - **验收：** 生产 E2E 确认 Canvas 覆盖 1440×1000 和 320×740 视口、默认回退页隐藏、JavaScript 禁用可读到全屏作品入口。

- [x] **W3.2 设计 DOM 与 Canvas 的事件/焦点桥**
  - 场景发出选择项目事件，HTML 面板读取注册表对应内容。
  - 面板用 dialog 或等效语义，显示项目说明、状态和明确 CTA；Escape、关闭按钮和焦点返回工作。
  - HUD 提供开发笔记入口；游戏内项目物件用鼠标/触屏或键盘打开介绍，不出现常规项目索引。
  - **验收：** Tab 顺序合理；面板开闭不丢焦点；读屏内容包含项目名、状态、简介和 CTA。

- [x] **W3.3 接入现有主题并限定主页作用域**
  - 新视觉规则使用 `assets/world/` 的专属样式作用域，不修改仍被博客或游戏外壳使用的共享样式语义。
  - 移除主页特有的黑客化主视觉依赖（启动屏、故障标题、CRT 遮罩等）时先确认它们没有被共享模块引用；博客/子游戏保持可独立运行。
  - 减少动态效果规则集中在世界入口；音效维持默认静音；世界脚本失败不会留下过时加载 UI。
  - **验收：** 首页与各子页面的样式、导航互不串扰；`dev-blog` 生成结果仍正常；共享 `shell.js` 入口未破坏。

- [x] **W3.4 完成端到端和失败降级测试**
  - Playwright 覆盖桌面键盘、项目点击、项目预览、触屏点击、Escape/焦点、移动布局和 reduced-motion。
  - 拦截 world runtime 入口做失败注入，确认全屏回退页、项目链接和笔记入口正常。
  - 对无效图片/Tilemap做失败注入，显示可理解的 fallback，不产生未捕获 Promise rejection。
  - **验收：** 所有浏览器测试在 CI 可重复；测试不使用生产 CDN 或网络不稳定资源。

- [x] **W3.5 本地生产根路径和资源预算检查**
  - 本地静态预览根路径与最终主机根路径一致；所有场景资源从 `/assets/world/runtime/` 同源加载。
  - 自动检查 runtime 输出、引用路径、404、错误控制台和静态文件可用性。
  - 记录生产入口 gzip、必要 sprite/tileset 总量与专属活动延迟请求；本机未记录 Lighthouse mobile 报告，发布前仍需补测。
  - **验收：** 本地生产 E2E 同源路径通过；JS gzip 约 365 KiB ≤ 500 KiB；必要首屏图像 2.7 KiB ≤ 1 MiB；Lighthouse ≥ 80 尚未验收。

- [ ] **W3.6 发布前人工验收清单**
  - 桌面 Chrome：键盘完整流程、鼠标命中/悬停、窗口尺寸变化，全程不出现网页下方的目录区块。
  - 手机 Safari 或模拟 iOS：触屏点击地图物件、竖屏/横屏、浏览器工具栏变化，场景随可视区铺满。
  - Android Chrome：同源资产加载、触摸响应、像素缩放和性能。
  - reduced-motion：环境动画关闭，移动和访问项目仍可用。
  - 部署预览：直接输入首页、从游戏物件进入项目再返回、刷新首页、浏览器禁用脚本四条流程。
  - **验收：** 所有检查记录设备/浏览器版本和结果；阻断问题修复后才把 Gate 4 标记通过。

## 子规划验收

- 默认首页是全屏 RPG，不在游戏下方显示项目、笔记或关于板块；项目可从场景物件进入。
- 根首页与各项目子目录仍能独立从静态托管路径打开。
- Canvas 失败、引擎失败、素材失败、JavaScript 禁用四种情形均有全屏可用入口。
- 游戏 HUD、项目面板和回退页有语义化标题与操作；搜索引擎仍可索引页面 SEO 元数据。
- 所有构建资产由同源 URL 提供；没有新增运行时第三方 CDN 必需项。
- 自动与人工验证矩阵均通过，性能预算有实测记录。

## 执行记录

- 默认首页按用户纠正改为全屏 RPG；HUD 只保留品牌、开发笔记入口和控制提示。项目只从地图物件进入；异常时同一视口显示自动生成的项目链接。
- `fitMapToViewport` 使首页随浏览器视口调整逻辑分辨率与镜头缩放，并响应窗口/手机方向变化；场景测试夹具继续沿用固定逻辑视口。
- `npm run typecheck`、`npm run test:unit`（16 项）、`npm run test:e2e`（10 项）、`npm run build`、`npm run verify:dist` 和 `npm run test:e2e:production`（7 项，修正旧导航断言后重跑）通过。
- 生产根路径 Playwright 覆盖全屏视口、场景事件到项目面板、运行时入口拦截、地图素材加载失败、禁用 JavaScript 和窄屏。人工检查 1440×1000 桌面与 320×740 手机截图：世界铺满视口、像素未拉伸、HUD 与内容区没有横向溢出。
- GitHub Pages 远端配置曾返回 404；未进行发布。Safari/iOS、Android 真机和 Lighthouse 成绩留给部署预览前验收。
